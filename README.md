# autotest-assets

Public, redistributable tool bundles fetched by `autotest install` on headless/Session-0 Windows boxes where the vendor GUI installer hangs.

- `nmap-portable-win-x64.zip` — portable nmap (nmap.exe + DLLs + data, no Npcap; connect-scan `-sT` works driverless), repackaged from the official nmap 7.95 Windows installer.
